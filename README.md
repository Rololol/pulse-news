# Pulse News
Mobile-first news dashboard. News is generated into `data/news.json` by GitHub Actions from RSS sources. The site is static and can be hosted on GitHub Pages.

## Current sources
Tagesschau, Deutsche Welle, BBC World/Technology/Science, Guardian World/Science/Business, NASA Breaking News and NPR.

## Important
The app displays headlines, short summaries and links back to publishers. It does not copy full articles. Source terms/licensing must be respected. AI summaries can be added later through a GitHub Actions secret.

## Mobile
Open the GitHub Pages URL on your phone and use “Zum Home-Bildschirm”.
